# VRCTeletubbylandAssets
The Assets folder of a Legacy (Unity 2019.4.31f) Teletubbyland VRC world.<br>

Updated project to 2022.3.22f1<br>
Warning: Broken prefab and materials<br>

<br>
Steps to import:<br>
1. Copy Assets, Packages and ProjectSettings folder to a new project folder.<br>
2. Add Existing Project on VCC and select the new project folder.<br>
3. Click Manage Project and Resolve project if needed.<br>
4. Click Open Project.<br>
5. Navigate to Asset > Scenes and open SampleScene to access the Teletubbyland.<br>
